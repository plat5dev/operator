# Slice 1

Get a staff request through. JWT in, path out, attribution logged. No authz.

Slice 2 replaces the attribution log with the audit log and changes request ids ([`v2.md`](v2.md)).

## Pieces

| Piece | Does | Does not |
|-------|------|----------|
| Gateway (Go, standard library proxy) | Validates the staff JWT. Matches its own route list. Strips credentials. Forwards the path. Writes the attribution log. CORS for listed origins. Health on the internal port | Serve UI. Store accounts. Read cookies. Call a decision service |
| Compose | Gateway, Dex as the staff IdP, an echo upstream for smoke tests | Run Plat5 or identity |

## Config

| Variable | Default | |
|----------|---------|--|
| `ADDR` | `:5004` | API listener |
| `INTERNAL_PORT` | `8004` | `/health/live`, `/health/ready` |
| `ROUTES_FILE` | `routes.yml` | [`routes.md`](routes.md) |
| `AUTH_ISSUER`, `AUTH_JWKS_URI`, `AUTH_AUDIENCES`, `AUTH_OPERATOR_ID_CLAIM` | | [`idp.md`](idp.md) |
| `ALLOWED_ORIGINS` | empty | Comma-separated. [`model.md`](model.md) |
| `UPSTREAM_TIMEOUT_MS` | `30000` | Time to response headers. Exceeded → **503** |

`/health/ready` is **503** until the route file is loaded and JWKS has been fetched once.

`AUTHZ_URL` set refuses boot in this slice. A deployment that sets it expects enforcement, and this slice has none.

## The hole

Any authenticated operator may name any target and call any route. That is accepted until slice 3. Do not add a role check, a groups check, or an allow-list in the request path to look ready. Slice 3 closes it through [`authz.md`](authz.md) and nothing else.

## Not in this slice

- Authz ([`authz.md`](authz.md))
- API keys
- A console
- A shared route source with the customer route-registry

Ready conditions are in [`AGENTS.md`](../AGENTS.md).
