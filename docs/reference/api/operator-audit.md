# operator-audit API

The staff audit event, its read API, and the gateway's writes. Concept: [audit](../../concepts/audit.md).

## Event

```json
{
  "id": "01JA2Z6Q3Y8D5V2K9N4R7T1W0X",
  "occurred_at": "2026-10-09T18:30:00.123Z",
  "request_id": "9f2c4e1a7b3d4c8e9a0b1c2d3e4f5a6b",
  "actor": {
    "issuer": "https://staff.example.okta.com/oauth2/default",
    "operator_id": "00u1abc",
    "email": "a@example.com",
    "client_id": "operator-console"
  },
  "acting_as": { "member_id": "m_01J9ZX6N…", "principal": "person" },
  "root_id": "n_01J9ZX4K…",
  "nodes": [ { "kind": "organization", "id": "n_01J9ZX4K…" }, { "kind": "project", "id": "n_01J9ZX5A…" } ],
  "service": "e10s",
  "method": "POST",
  "route": "/as/{member}/projects/{project_id}/plans/{key}/versions",
  "params": { "member": "m_01J9ZX6N…", "project_id": "n_01J9ZX5A…", "key": "pro" },
  "path": null,
  "ip": "10.0.4.17",
  "user_agent": "Mozilla/5.0 …",
  "outcome": "responded",
  "status": 201,
  "response_bytes": 312,
  "details": { "version": 7 },
  "created_id": "ver_01JA2Z6R…"
}
```

| Field | |
|-------|--|
| `id` | ULID, assigned by operator-audit when the intent is written |
| `occurred_at` | When the gateway received the request. UTC, milliseconds |
| `request_id` | `X-Request-ID`, generated by the gateway. Joins to every service log line |
| `actor` | The operator ([`reference/idp.md`](../idp.md#the-actor)) |
| `acting_as` | `{ member_id, principal }` on an `/as/{member}` request whose member passed the check. `null` otherwise |
| `root_id` | `nodes[0].id`, or `null` when `nodes` is `[]` |
| `nodes` | The route node's chain, root first, as `{ kind, id }`. `[]` when the route has no `node`, no route matched, or the chain wasn't found |
| `service` | The service's name in the route file. `null` when no route matched |
| `method` | HTTP method |
| `route` | The matched path template, `/as/{member}` included when acting as a member. `null` when no route matched |
| `params` | Path params by name, as matched. `{}` when there are none, or no route matched. Bytes Postgres can't store (invalid UTF-8, NUL) are recorded as U+FFFD |
| `path` | The raw path, escaped as received, cut to 2048 characters. Set only when no route matched; otherwise `null` |
| `ip` | The TCP peer of the connection. Behind a proxy, the proxy's address. `X-Forwarded-For` isn't read |
| `user_agent` | `User-Agent`, cut to 512 characters. `null` when absent |
| `outcome` | `pending`, `rejected`, `responded`, `no_response` ([below](#outcome)) |
| `status` | The status the gateway answered with. `null` while `pending`, or when the client was gone before an answer |
| `response_bytes` | Response body bytes written to the client. `null` while `pending` |
| `details` | From `X-Plat5-Audit-Details`, or `null` |
| `created_id` | From `X-Plat5-Audit-Created`, or `null` |

| `outcome` | Means | The change |
|-----------|-------|------------|
| `pending` | Intent recorded, no outcome | Unknown |
| `rejected` | The gateway answered without calling the service | Didn't happen |
| `responded` | The service answered. `status` is its status | Per `status` |
| `no_response` | The gateway called the service and got no answer (**502**) | Unknown |

Not in an event: request or response bodies, the query string, headers other than `User-Agent`, the token, claims other than the actor fields, or any customer credential.

## Reading

```
GET /operator-audit-events
```

On operator-audit's public port, published through the gateway, so each read is itself an event.

| Query | |
|-------|--|
| `limit`, `starting_after` | As Plat5's lists (Plat5 `docs/reference/lists.md`): default 50, max 100, over-max clamped; `starting_after` is the last `id` of the previous page, a ULID |
| `operator_id` | The acting operator |
| `acting_as_member_id` | The member acted as |
| `node_id` | Events on this node or below it: any event whose `nodes` contains it |
| `service`, `method`, `outcome`, `request_id`, `created_id` | Exact match |
| `route` | Exact template, e.g. `/nodes/{node_id}/bindings` |
| `params[<name>]` | A path param's value, e.g. `params[member_id]=m_01J…`. One per name; several names AND |
| `occurred_after`, `occurred_before` | RFC 3339. After is inclusive, before is exclusive |

Filters AND. An unknown query param, a repeated one, or a malformed value → **422** `VALIDATION_ERROR`.

```json
{ "audit_events": [ ... ], "has_more": false }
```

Ordered by `id`, newest first, as Plat5's audit reads are. `starting_after` continues the walk to older events.

## Internal API

On operator-audit's `INTERNAL_PORT`, not routed through the gateway. Every call carries `Authorization: Bearer <INTERNAL_TOKEN>`; missing or wrong is **401**. Only the gateway writes the staff log.

### Intent

```
PUT /internal/events/{request_id}

{
  "occurred_at": "…",
  "actor": { "issuer": "…", "operator_id": "…", "email": "…", "client_id": "…" },
  "acting_as": null,
  "root_id": "…", "nodes": [ { "kind": "…", "id": "…" } ],
  "service": "…", "method": "…", "route": "…", "params": { … }, "path": null,
  "ip": "…", "user_agent": "…"
}
```

| Result | Response |
|--------|----------|
| Written | **201** |
| An event for this `request_id` exists | **200**, unchanged |
| Malformed | **422**. See below |
| Postgres unavailable | **503**. The gateway retries |

Malformed includes: `occurred_at` more than 24 hours from operator-audit's clock; `route` and `path` both set or both `null`; `service` set exactly when `route` is not; `root_id` other than `nodes[0].id`, or set with `nodes` empty; `nodes` or `acting_as` without a `route`; `acting_as` with `nodes` empty; more than 32 nodes. A retry sends the same body. Unknown fields are ignored, so a newer gateway can send more.

### Outcome

```
PATCH /internal/events/{request_id}

{ "outcome": "responded", "status": 201, "response_bytes": 312, "details": { … }, "created_id": "…" }
```

| Result | Response |
|--------|----------|
| Applied, or the event is already final | **204**. A final event is left unchanged |
| No event for this `request_id` | **404**. The gateway stops retrying |
| Malformed, or `outcome: pending` | **422** |
| Postgres unavailable | **503**. The gateway retries |

`status` may be `null` only when the client was gone before an answer, so never with `responded`. `details` and `created_id` may be set only with `responded`. `response_bytes` is a non-negative integer.
