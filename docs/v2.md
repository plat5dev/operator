# Slice 2

Record every staff request before it reaches a service. The contract is [`audit.md`](audit.md). There is no authz yet.

## Pieces

| Piece | Does | Does not |
|-------|------|----------|
| Gateway | Generates every request id. Writes the audit intent before it answers or forwards, and the outcome after. Reads and strips `X-Plat5-Audit-Details`. Serves `/metrics` on the internal port | Accept a client request id. Read `X-Forwarded-For`. Call a decision service |
| `operator-audit` (Go, this repo) | Stores events in Postgres. Serves `GET /operator-audit-events`. Takes intent and outcome writes on its internal port. Keeps monthly partitions | Purge or export events. Serve customers. Run as a role that can delete |
| Route files | `routes.yml` and `compose/routes.yml` add the `operator-audit` upstream and its read route | |
| Compose | Dev and prod add Postgres, with owner and writer roles, and operator-audit, which runs `migrate` before `serve` | Move Dex off memory storage |

## Config

The gateway adds these variables. The rest of its config is unchanged from [`v1.md`](v1.md#config).

| Variable | Default | |
|----------|---------|--|
| `AUDIT_ENABLED` | `true` | `false` turns audit off for the deployment. [`audit.md`](audit.md#the-model) |
| `AUDIT_URL` | | Required unless audit is off. [`audit.md`](audit.md#gateway-env) |
| `AUDIT_TOKEN` | | Required unless audit is off. [`audit.md`](audit.md#gateway-env) |

Operator-audit's config is in [`audit.md`](audit.md#runtime).

The gateway's `/health/ready` is unchanged and does not probe operator-audit.

Setting `AUTHZ_URL` still refuses boot. Authz is slice 3.

## Changes from slice 1

- A client's `X-Request-ID` is no longer accepted. This gateway generates every request id.
- `X-Plat5-Audit-Details` is now stripped from requests and responses on every route. Slice 1 passed it through.
- With audit on, every authenticated request gets **503** while operator-audit is down.
- The request log line stays, for operations. The audit log is the record of who did what.

## The hole

The hole is still open: any authenticated operator may name any target and call any route, including the staff log read. With audit on, every such call is now recorded. Do not add a role check, a groups check, or an allow-list in the request path to look ready. Slice 3 closes the hole through [`authz.md`](authz.md) and nothing else.

## Not in this slice

- Authz ([`authz.md`](authz.md)). Slice 3
- Trusted proxies for an event's `ip`
- A reason or ticket on staff requests
- Staff access shown to customers
- Configurable actor claims
- Audit retention, purge, and export to WORM storage or a SIEM

Ready conditions are in [`AGENTS.md`](../AGENTS.md#deferred).
